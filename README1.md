# Retail Sales Analysis

## Project Overview

This project performs end-to-end analysis of retail sales data using Python. The analysis explores sales performance, products, categories, regions, customer demographics, payment methods, and monthly sales trends.

## Objectives

* Analyze retail sales data
* Identify top-performing products and categories
* Compare regional sales performance
* Understand customer demographics
* Analyze payment methods
* Identify monthly sales trends
* Generate useful business insights

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Analysis Performed

* Data inspection and validation
* Statistical analysis
* Product and category analysis
* Regional sales analysis
* Customer analysis
* Payment method analysis
* Monthly sales trend analysis
* Data visualization

## Key Metrics

* Total Sales
* Total Quantity Sold
* Average Order Value
* Best-Selling Product
* Best Product Category
* Best-Performing Region
* Average Customer Age

## Project Files

* `Retail_Sales_Analysis.ipynb` – Complete analysis and visualizations
* `retail_sales.csv` – Retail sales dataset
* `README.md` – Project documentation

## Outcome

The project demonstrates the application of data science techniques to a real-world retail scenario and provides business-oriented insights through data analysis and visualization.
